Personal Portfolio Website

About the Project

This project is a responsive and accessible personal portfolio website developed as part of the Thiranex Web Development Internship task. It showcases my skills, projects, learning goals, and contact information.

Objectives

- Create a well-structured website using HTML5 semantic elements.
- Improve website accessibility and usability.
- Implement responsive design for mobile and desktop devices.
- Follow basic SEO best practices.

Technologies Used

- HTML5 – Website structure and semantic elements.
- CSS3 – Styling and responsive layouts.
- JavaScript – Interactive navigation and form feedback.

Website Pages

1. Home – Introduction and technical skills.
2. About – Background and learning goals.
3. Projects – Showcase of projects.
4. Contact – Accessible contact form.

Accessibility Features

- Semantic HTML5 elements such as "header", "nav", "main", "section", and "footer".
- Skip-to-main-content link.
- Labels for form fields.
- ARIA attributes for navigation and status messages.
- Keyboard-friendly navigation and visible focus indicators.
- Responsive layout for different screen sizes.

SEO Features

- Page titles.
- Meta descriptions.
- Viewport configuration.
- Descriptive page content.

How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open "index.html" using the Live Server extension.
4. Navigate through the Home, About, Projects, and Contact pages.

Learning Outcomes

Through this project, I practised semantic HTML5, accessibility principles, responsive CSS design, and basic JavaScript interactions.
